# S2Arm v0.6.3

这是 0.6.2 的修复版：修复 Apple ID 登录失败（503）；修复 iPhone 全新安装后导入游戏、起局时初始化失败；修复部分游戏的早期版本在 iPhone 上启动即闪退；游戏库可以把一款游戏加到 iPhone 主屏幕；修复 Mac 上一类可能导致随机崩溃的栈数据被覆盖；降低开着文件后备时的额外开销。
*A fix release for 0.6.2: it fixes Apple ID sign-in failing with 503, fixes games failing to initialize at launch after a fresh install on iPhone, and fixes early versions of some games crashing at launch on iPhone. You can also add a game from the library to the iPhone Home Screen; it fixes a kind of stack-data overwrite on Mac that could cause random crashes and lowers the extra overhead while file backing is on.*

## 新功能
- **iPhone：游戏库长按「添加到主屏幕…」**：在游戏库里长按一款，选「添加到主屏幕…」，按三步引导在 Safari 里加到主屏幕；之后点主屏上这个图标直接进这款游戏。图标用这款的封面。游戏号、名字和封面只放在链接里交给本机 Safari，官网看不到你有哪些游戏。
  *iPhone: long-press a game in the library and choose Add to Home Screen…. Follow the three steps in Safari to add it; tapping that Home Screen icon then opens the game directly, with the game's cover as the icon. The game ID, name and cover stay in the link handed to Safari on your device, so the website cannot see which games you have.*

## 改进
- **降低开着文件后备时的额外开销（#1842）**：游戏内存用文件后备时，后台心跳只看游戏放开过的那部分内存，不再每 10 秒扫一遍整块；记需求时把已写回、已移出内存的页也算进去；玩家局缺省关掉调度诊断。
  *Lower extra overhead while file backing is on (#1842). When game memory is backed by a file, the background heartbeat now only looks at the parts the game has released instead of scanning the whole region every 10 seconds; pages already written back and moved out of memory are counted when tracking demand; and scheduling diagnostics are off by default in player sessions.*
- **出包时管线归档这一段更快**：这一段的编译进程不再通过复制主进程来启动，能吃满并行路数。
  *Faster pipeline archiving during packing. The compiler processes for this step no longer start by copying the main process, so they use all parallel slots.*
- **启动器界面修正：手机图标位置、设备列表、窄窗与英文排版等**：Mac / Windows 总控台里手机图标不再压住边框；连着的设备列表不再混进模拟器和手表；窗口拉窄或用英文界面时排版不再挤乱。
  *Launcher layout fixes: phone icon position, device list, narrow windows and English layout. On Mac and Windows the phone icon in the phone console no longer overlaps its border, the list of connected devices no longer includes simulators and watches, and the layout no longer gets cramped in narrow windows or in English.*
- **Mac：地址空间不够这款的提示带上处理建议**：提示条出现时，旁边会写明可以怎么办。
  *Mac: the notice that a game does not fit the address space now says what you can do about it.*

## 修复
- **修复 Apple ID 登录失败（503）**：11 月 20 日起，在 Mac 和 Windows 上用 Apple ID 登录会一直失败（报 503）。原因是随包签名工具向 Apple 报的系统名写法从这天起被 Apple 拒收，和网络、DNS 无关。现在改成 Apple 接受的写法，能正常登录、安装。
  *Fixed Apple ID sign-in failing with 503. Since November 20, signing in with an Apple ID on Mac and Windows kept failing with 503. The bundled signing tool reported the system name in a form Apple stopped accepting that day; it has nothing to do with your network or DNS. It now uses the form Apple accepts, so sign-in and installing work again.*
- **修复 iPhone 全新安装后导入游戏、起局时初始化失败**：在 iPhone 上全新安装 S2Arm、之后再导入游戏的，起局时游戏运行环境初始化失败，进不了游戏。现在能正常起局。
  *Fixed games failing to initialize at launch after a fresh install on iPhone. If S2Arm was freshly installed on an iPhone and games were imported afterwards, the game runtime failed to initialize at launch and the game would not start. It now starts normally.*
- **修复部分游戏的早期版本在 iPhone 上启动即闪退**：0.6.0 起，部分早期版本的游戏在 iPhone 上一启动就闪退。现在能正常进游戏。
  *Fixed early versions of some games crashing right at launch on iPhone. Since 0.6.0, some early game versions crashed as soon as they started on iPhone. They now start normally.*
- **修复 Mac 上一类可能导致随机崩溃的栈数据被覆盖（#515）**：Mac 上抢占游戏线程时，原先会写到游戏还在用的栈数据上，可能在随机的时刻导致崩溃。现在抢占改在每个线程专用的栈上进行，不再碰游戏的数据。
  *Fixed a kind of stack-data overwrite on Mac that could cause random crashes (#515). When preempting a game thread on Mac, S2Arm could write over stack data the game was still using, which could crash at random moments. Preemption now runs on a stack reserved for each thread and no longer touches the game's data.*

## 系统要求
- 与 0.6.2 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.2: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
